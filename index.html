Appairer la montre

Sur la montre : ouvrez CarteGPS, appui long sur UP, puis « Code d'appairage ».

Où allez-vous ?

    Aucun trajet

    Choisissez ce que place un appui sur la carte (arrivée, étape ou départ). Glissez les points pour modifier le trajet, touchez une étape pour la retirer. Le départ ne sert qu'à l'aperçu : la montre partira de sa propre position.

    Favoris

      Ajoutez un favori avec ☆. Ils apparaissent aussi sur la montre (menu > Destinations).

      Réglages avancés

      Serveur de tuiles de la carte de la montre. Laissez vide pour garder celui par défaut.

      L'app CarteGPS doit être ouverte sur la montre : elle relève les messages toutes les 20 secondes. Carte et recherche © contributeurs OpenStreetMap, itinéraires Valhalla (FOSSGIS).
